# Högemann Spiele - Score & Data Management System

This repository contains the source code for a database-driven desktop application developed during my Software Engineering Internship at Franz Högemann GmbH in Garrel, Germany. 

## Project Overview
The application is designed to manage, rank, and process user scores and game data efficiently. It is built using **Delphi / Object Pascal** and relies on a **Firebird** relational database. The project demonstrates the ability to build robust GUI applications with complex backend data operations, focusing on data integrity, searchability, and controlled workflows.

## Key Features
*   **Database Integration:** Seamlessly connected to a Firebird database using FireDAC components for high-performance data access.
*   **SQL-Backed Search & Ranking:** Implemented advanced SQL queries to filter user data dynamically and calculate score rankings in real-time.
*   **Data Import/Export:** Engineered automated CSV import and export functionalities, allowing smooth data migration and reporting.
*   **Backup & Restore Workflows:** Built secure, controlled reset and database backup workflows to prevent accidental data loss.
*   **VCL User Interface:** Developed a clean, responsive, and user-friendly desktop interface for seamless data entry and monitoring.

## Technologies Used
*   **Language:** Delphi / Object Pascal
*   **Framework:** VCL (Visual Component Library)
*   **Database:** Firebird SQL
*   **Data Access:** FireDAC
*   **Data Formats:** CSV, SQL

## Technical Highlights
This project highlights my ability to handle full-stack desktop application development, from UI design to SQL database management. By implementing fail-safes like controlled reset workflows and backup mechanisms, the application is optimized for reliable, everyday administrative use.
